# PRD: «Угадай эпоху!»

**Статус:** опубликовано на GitHub Pages: <https://teterkin.ru/ugadai-epokhu/>

## Цель

За 1–2 минуты проверить, насколько игрок узнаёт эпохи России 1980–2026 по технологиям, кино, музыке, играм и событиям, и получить результат с пояснениями.

## Не-цели

- Бэкенд, аккаунты, рейтинги, мультиплеер.
- Аудио, видео, внешние шрифты, CDN и картинки.
- Отдельная тема «Книги».
- Зависимость от Telegram Mini App SDK.
- Деплой и настройка хостинга без отдельного запроса.

## User story

Как пользователь Telegram, я хочу открыть одну ссылку, быстро пройти викторину и поделиться результатом, чтобы сравнить себя с друзьями.

## Подтверждённые решения

1. Один тип вопроса: показан факт — нужно выбрать эпоху из 4 вариантов.
2. Политические события включаются нейтрально, как в файле-источнике.
3. Визуальный стиль: тёмный ретро-неон с таймлайном.
4. Служебные файлы, тесты и документация допустимы; игра остаётся одним `index.html`.
5. Деплой выполнен по отдельному подтверждению: GitHub Pages, <https://teterkin.ru/ugadai-epokhu/>.

## Acceptance criteria

1. `index.html` — единственный файл, нужный для игры; открывается с `file://` и по HTTP, не содержит внешних `script/link/img` и сетевых запросов.
2. Банк: ровно 60 вопросов = 5 тем × 6 эпох × 2; `python3 tests/validate_bank.py` завершается с кодом 0.
3. В каждом вопросе 4 варианта эпох, ровно один правильный; цитата и ячейка-источник проверяются валидатором по xlsx.
4. Раунд — 10 вопросов без повторов: в смешанном режиме по 2 из каждой темы, не более 2 из одной эпохи; в режиме темы — только эта тема.
5. После ответа выбор блокируется, верный/неверный вариант подсвечивается, показывается пояснение с эпохой и фактом; счёт растёт только за верный ответ.
6. Финал: `X/10`, текстовый тир, лучший результат; «Ещё раз» запускает новый раунд, «Сменить тему» возвращает на старт.
7. Лучший результат хранится в `localStorage` и не ломает игру, если storage запрещён.
8. `./tests/run_e2e.sh` проходит: старт → 10 верных → `10/10` → рестарт; неверный ответ; фильтр «Кино»; клавиши `1–4` и `Enter`.
9. На 320×568, 390×844, 430×932 и desktop нет горизонтального скролла, все кнопки ≥44×44 px, учтены safe-area; скриншоты проверены.
10. Ручная проверка в Telegram in-app browser на iOS и Android: старт, ответ, результат, рестарт — без обрезки и залипаний.

## Источники и допущения

- `russia_encyclopedia_1980_2026.xlsx`: листы «Сводная матрица», «Связь и ИТ-сервисы», «Политика и криминал», «Кино, музыка, книги, игры»; строки 4–10, шесть эпох.
- Вопросы используют точные цитаты из ячеек; промпт не содержит года, пояснение содержит факт и эпоху.
- Telegram in-app browser рассматривается как обычная HTTPS-ссылка, не Mini App; SDK не обязателен.
- xlsx — источник истины; фактчекинг вне файла не входит в задачу.

## Риски

- Различия WebView на iOS/Android: используются `100dvh` с fallback, safe-area, без `position: fixed` и `alert`; обязательна ручная проверка.
- Пограничные факты: берутся только однозначные цитаты, валидатор сверяет строку эпохи.
- Спорные или будущие факты из файла: нейтральные формулировки, без оценок.
- Для Telegram нужен публичный HTTPS-URL; отправка `.html` файлом игру не откроет.
- `localStorage` и share в WebView могут быть ограничены; предусмотрены graceful fallback.
